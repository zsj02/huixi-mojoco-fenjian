# 旋钮测温扩展走廊

与 baseline 相同的柜体布局，4 个普通按钮、4 个旋转 90° 后按压的按钮、8 个温度显示、工具桌与动态温度枪。测温策略留待后续。

启动：`python3 tools/view_environment.py 05_rotary_thermal_lab`；无界面：`python3 tools/view_environment.py 05_rotary_thermal_lab --headless`。

`world.sdf` 为独立世界，`scene.json` 为布局及评测元数据，`map.yaml` / `map.pgm` 为 Nav2 地图，`preview.svg` 为俯视示意。机器人在启动时单独生成。

## 触发与场景差异

初始 4 红 4 绿。按压总行程 0.012 m，至少推进 0.006 m 并保持 0.12 s 才触发变绿。偶数编号电箱必须先旋转 90° 解锁，其余电箱直接按压。

工具桌中心 XY=(4, -1.65)，桌面中心高度 0.72 m、尺寸 1.2 × 0.65 m、厚 0.05 m；温度枪为可抓取动态物体。8 柜温度为场景显示值，测温与上报策略尚未实现。

详细控制接口与运行限制见根目录文档。几何信息更新后应重新生成本文件，冻结实验源码副本不随主线文档改写。
