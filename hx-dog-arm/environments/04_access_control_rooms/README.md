# 刷卡开门双机房

两室各 4 柜。动态门、实体门禁卡、读卡区、可旋转把手、受锁约束的门铰链。

启动：`python3 tools/view_environment.py 04_access_control_rooms`；无界面：`python3 tools/view_environment.py 04_access_control_rooms --headless`。

`world.sdf` 为独立世界，`scene.json` 为布局及评测元数据，`map.yaml` / `map.pgm` 为 Nav2 地图，`preview.svg` 为俯视示意。机器人在启动时单独生成。

## 触发与场景差异

初始 4 红 4 绿。按压总行程 0.012 m，至少推进 0.006 m 并保持 0.12 s 才触发变绿。本环境全部为普通按钮，没有旋转解锁要求。

隔墙位于 X=0，将12 × 4.8 m的总场地分为两室；每侧名义长度6 m，中央墙厚0.2 m，隔墙表面至端墙之间净长5.9 m。门叶尺寸0.08（厚）× 1.60（宽）× 2.28（高）m；读卡器中心(-0.17, -1.22, 1.00)，把手关节参考位置(-0.09, 0.58, 1.00)。门初始锁定，需实体卡刷卡、旋转把手并推门；不得将门后区域视为已经检查。几何中心(0, 0)位于门洞，默认出生点在A室。

详细控制接口与运行限制见根目录文档。几何信息更新后应重新生成本文件，冻结实验源码副本不随主线文档改写。
